## ⚡ About

WIFOO is a lightweight Python-based wireless network discovery and analysis tool built for Termux.

Designed with a powerful terminal interface, interactive network selection, and detailed wireless information display.

## 🔥 Features

- Wireless network discovery
- SSID identification
- Security protocol detection
- Signal strength information
- Interactive network selection
- Terminal-based analysis engine
- Animated terminal interface
- Configurable external result pages
- Android and Termux support

## 🛠️ Built With

- Python 3
- Termux
- Termux:API

## 📲 Installation

```bash
git clone https://github.com/arafatlab/WIFOO
pip install -r requirements.txt
pkg install termux-api -y
```
